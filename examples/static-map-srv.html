Static Map via Service Call

Fetches a static map from the /static_map service using nav_msgs/GetMap. This is the standard interface provided by the ROS map_server package.

Requirements

  1. roscore
  2. rosrun map_server map_server /path/to/map.yaml
  3. roslaunch rosbridge_server rosbridge_websocket.launch

Difference from Topic-based Loading

  • Service call: One-time fetch, map loaded once
  • Topic subscription: Can receive updates (useful for SLAM)
