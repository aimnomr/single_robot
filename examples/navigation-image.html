Navigation Image

Displays custom images as markers using NavigationImage. Unlike shape-based markers, you can use any PNG/SVG image.

Features

  • size: Controls the display size in meters
  • image: URL to the image file
  • pulse: Optional pulsing animation
  • alpha: Transparency (0-1)

Use Cases

  • Custom robot icons for multi-robot visualization
  • Branded markers for specific locations
  • Pictograms for points of interest

Note: The robot icon rotates to demonstrate orientation control.
