Path Visualization

Demonstrates two path visualization types:

PathShape (Green)

Visualizes a nav_msgs/Path message. Used for:

  • Global planner paths from /move_base/NavfnROS/plan
  • Local planner paths from /move_base/DWAPlannerROS/local_plan
  • Any pre-computed path visualization

TraceShape (Red)

Records and displays robot position history. Used for:

  • Visualizing where a robot has traveled
  • Odometry drift visualization
  • SLAM trajectory display

The trace automatically removes old points when maxPoses is reached, and only adds points when the robot moves more than minDist.
