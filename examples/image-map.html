Image Map Example

Displays a PNG image as a map. The image is scaled to fit the dimensions received from the /map_metadata topic.

Requirements

  1. roscore
  2. A node publishing to /map_metadata (nav_msgs/MapMetaData)
  3. roslaunch rosbridge_server rosbridge_websocket.launch

Example: Publishing map metadata

rostopic pub /map_metadata nav_msgs/MapMetaData '{
  resolution: 0.05,
  width: 1024,
  height: 1024,
  origin: {
    position: { x: -25.6, y: -25.6, z: 0 },
    orientation: { x: 0, y: 0, z: 0, w: 1 }
  }
}'
