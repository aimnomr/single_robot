Grid Visualization

The Grid component provides a coordinate reference overlay. Multiple grids can be layered for different scales.

Parameters

  • size: Number of cells in each direction from origin
  • cellSize: Size of each cell in meters
  • lineWidth: Thickness of grid lines

Use Cases

  • Reference overlay on occupancy grid maps
  • Visual scale reference in RViz-like displays
  • Coordinate system demonstration
  • Measuring distances visually

In this example, two grids are layered: a 1-meter grid for coarse reference and a 20-centimeter grid for fine positioning.
